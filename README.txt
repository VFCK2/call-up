# 消防団 災害時参集状況

GAS + Googleスプレッドシートで動くスマホ向けプロトタイプです。

## 初期設定

1. Googleスプレッドシートを1つ作成
2. 拡張機能 → Apps Script
3. `Code.gs` と `index.html` を追加
4. `Code.gs` の `REGISTRATION_CODE` を団内用コードに変更
5. `setup()` を一度実行してシートを作成
6. 「団員」シートへ団員を登録

団員シート:
ID | 部 | 氏名 | 有効
001 | 1 | 例：団員A | TRUE
002 | 1 | 例：団員B | TRUE

7. ウェブアプリとしてデプロイ
   - 実行ユーザー: 自分
   - アクセス: 必要な範囲に設定

## 端末認証

初回だけ登録コードを入力し、端末トークンをブラウザへ保存します。
以後はログイン画面を表示しません。

※これは「団内利用のための簡易端末認証」です。ブラウザのデータ消去や別端末では再登録が必要です。
※本格的な端末固有認証ではありません。

## 参集データ

「参集」シートに最初に押した時刻を保存します。
同じ団員を再度押しても時刻は上書きしません。
